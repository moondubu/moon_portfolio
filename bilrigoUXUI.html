Overview

2025.03 ~ 2025.04 기존 서비스의 UI 노후화와 일관성 부족을 개선하기 위해 빌리고 UX/UI 리뉴얼을 기획했습니다.
Microsoft Clarity를 통해 수집한 사용자 행동 데이터와 기존 서비스 구조를 분석하고, 메인·상품 리스트·렌탈료 비교 등
주요 화면의 탐색성과 사용성을 개선하는 방향으로 UX/UI를 재설계했습니다.
UX 기획, UI 디자인 및 프로토타이핑까지 진행했으며, 퇴사로 인해 실제 서비스에는 반영되지 않았습니다.

Prototyping

Typography

기존에는 작업자와 페이지마다 서로 다른 폰트와 스타일을 사용하여 디자인의 일관성이 부족했습니다.
이를 개선하기 위해 SUIT를 기반으로 텍스트의 역할에 따른 크기, 굵기, 행간 등의 기준을 정의하고,
서비스 전반에 일관되게 적용할 수 있는 타이포그래피 시스템을 구축했습니다.

하단 네비게이션의 활성화 상태와 주요 기능별 아이콘을 정의하고, 일관된 디자인 스타일을 적용할 수 있도록 구성했습니다.

UX Analysis

Microsoft Clarity를 활용해 메인, 상품 리스트, 렌탈료 비교 등 주요 화면의 사용자 행동 데이터를 분석했습니다.
클릭 분포와 스크롤 도달률을 바탕으로 기존 UI의 문제점을 파악하고 리뉴얼 방향을 설정했습니다.

Click Distribution

주요 메뉴의 클릭 비중을 분석하여 사용자의 탐색 성향과 관심 영역 파악

Scroll Heatmap

페이지별 스크롤 도달률을 분석하여 주요 콘텐츠의 노출 현황을 파악하고
정보 배치의 우선순위 재설정

Lofi-Wire Frame → Lofi-Prototyping

로우파이 와이어프레임에 기반한 프로토타이핑 진행하여 플로우 체크

Main

Header

기존 상단 카테고리를 제거하고 검색 영역을 강조하여
사용자가 원하는 상품을 보다 직관적으로 탐색할 수 있도록 구성

Banner

배너별 디자인과 이미지 표현의 편차를 줄이고,
슬라이드 구조로 재설계하여 콘텐츠 간격의 효율성과 공간 활용도를 높임

Category

기존에는 스크롤해야 확인할 수 있었던 주요 카테고리를 상단에 배치하고,
맞춤상품 콘텐츠를 추가하여 상품 탐색을 유도

Best Item

카테고리별로 나열되던 상품 영역을 인기상품 중심으로 재구성하여
정보의 우선순위를 정리하고, FAQ 콘텐츠를 통한 궁금증 해소

List

Header

카테고리를 드롭다운 방식으로 간소화하고 헤더 높이를 축소하여 화면의 답답함 개선.
이를 통해 상품과 주요 콘텐츠의 노출 공간을 확보

Banner

무작위로 노출되던 배너를 카테고리 특성에 맞게 재구성하여
관련성 높은 콘텐츠 노출 및 배너 활용도 개선

Sub Category / Smart Filter

서브 카테고리는 가로 스크롤, 필터는 드롭다운 형태로 구성하여
화면 점유 최소화 및 상품 탐색 영역 확보

Item Information

기존 1열 상품 목록을 2열로 재구성하고 정보의 시각적 위계를 정리하여
공간 활용도 향상 및 상품 정보의 가독성 강화

Compare

Initial View

기존 상품별 이미지 중심의 정보 구조를 재구성하여
주요 상품 정보와 최저 렌탈료를 직관적으로 확인할 수 있도록 설계

Bottom Button

Compare 화면 전용 고정버튼을 배치하여 페이지 이동을 막으면서
지속적인 렌탈 상담 유도

Rental Price Card

렌탈사별 가격 정보를 카드 형태로 재구성하여
월 렌탈료와 계약 조건의 비교 및 선택 편의성 강화
