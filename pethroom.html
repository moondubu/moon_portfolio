Overview

2025.04 ~ 2026.04 120만 회원을 보유한 반려동물 커머스 ‘페스룸’의 퍼블리싱 고도화를 담당했습니다.
카페24 기반 환경에서 사내 빌더 시스템과 Git을 활용해 알파 검수부터 운영 배포까지 진행했으며,
신규·이벤트 페이지 제작, 사이트 전체 리뉴얼, 반응형 전환 프로젝트를 수행했습니다.

Link

Event / Promotion

디자인 시안을 기반으로 이벤트 및 프로모션 페이지를 퍼블리싱했습니다.
단순 화면 구현을 넘어 이벤트 기간에 따른 배너 노출 제어, 쿠폰 상태값 처리, 반응형 대응 등 운영 과정에서 필요한 기능까지 함께 구현했습니다.

Event rolling banner

이벤트 당일이 되지 않으면 배너가 정상적으로 롤링되는지 알 수 없던 기존 jQuery 코드를
파라미터를 활용하여 테스트할 수 있도록 신규 코드 작성하여 업무 프로세스 및 리스크 개선

반응형 대응

4K부터 iPhone mini까지 최적의 사이즈로
유저에게 제공될 수 있게 미디어쿼리 사용하여 대응

쿠폰 on/off 기능 추가

카페24 특성상 쿠폰의 스테이트값을 가져올 수 없기 때문에
쿠폰이 솔드아웃 되면 분기처리 된 CSS를 활용하여 UI 교체 기능 추가

New Page

브랜드 신규 페이지 및 콘텐츠 운영 목적에 따라 다양한 페이지를 제작했습니다.
기존 사이트 구조를 활용해 콘텐츠를 확장하면서 각 페이지의 목적에 맞는 레이아웃과 인터랙션을 구현했습니다.

상품 확장성 대비

신규 페이지인 vip mall에서 운영할 브랜드가 점차 늘어날 것을 대비하여
2개 이상일 때의 UI를 미리 구성하여 상품이 추가되면 별도의 작업없이
자동으로 UI가 바뀌도록 설계

미디어 리소스 최적화

용량이 큰 이미지와 영상은 CDN을 활용해 제공하고, 이미지 리소스는 WebP 등 최적화 포맷으로 변환하여
디바이스별 적절한 리소스를 사용해 초기 로딩과 화면 렌더링 부담을 줄이고 사이트 성능을 개선

Renewal

브랜드 개편에 맞춰 일부 사이트를 제외한 모든 페이지를 리뉴얼 퍼블리싱으로 전환했습니다.
기존 운영 구조를 유지하면서 신규 디자인 시스템을 반영하고, 공통 요소 및 페이지별 UI를 새롭게 구현했습니다.

컴포넌트 기반의 디자인 시스템 설계

기존에는 여러 페이지에서 공통으로 쓰인 헤더와 카드 등의
디자인을 각각 관리하여 유지보수의 부담이 있었습니다.
리뉴얼을 진행하면서 구조와 스타일을 재정리하고 공통 컴포넌트를 활용하여
페이지마다 동일한 형태, 폰트, 색상, 이미지 등을 유지할 수 있게 변경했습니다.

리뉴얼 신규 페이지

리뉴얼을 진행하면서 홈 화면의 신규 페이지를 추가하고
스크롤에 따른 인터랙션을 구현했습니다.
운영과 콘텐츠 확장에 맞는 화면 구조로 개선했습니다.

Responsive Conversion

기존 카페24 적응형 스킨을 반응형 스킨으로 전면 교체했습니다. 기존 디자인과 콘텐츠를 유지하면서 다양한 해상도에 대응하도록 구조를 재구성했으며,
반복적인 수정과 검증에는 AI Agent를 적극 활용해 작업 시간을 단축했습니다.
